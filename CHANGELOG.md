## [0.1.0] - 2026-10-26

### Added

- Inline size and alignment decorations for explicit C, C++, and CUDA C++
  `struct`, `union`, and `class` references.
- Microsoft C/C++ IntelliSense hover integration without compiling or running
  probe programs.
- Refresh command and settings for alignment display, debounce, reference
  limits, and query concurrency.
- Validation and warnings for required Microsoft C/C++ versions and hover
  settings.
- Unit and activation smoke tests.
